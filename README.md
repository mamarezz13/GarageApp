# GarageApp — نرم‌افزار مدیریت تعمیرگاه

## اجرا
1. Windows و .NET 8 SDK و Visual Studio 2022 را نصب کنید.
2. فایل `GarageApp.csproj` را باز کنید.
3. اجازه دهید NuGet پکیج `Microsoft.Data.Sqlite` را بازیابی کند.
4. با F5 اجرا کنید. دیتابیس `garage.db` کنار برنامه ساخته می‌شود.

## قابلیت‌های این نسخه
- مدیریت قطعات، قیمت خرید/فروش، دسته‌بندی و موجودی
- سود پیش‌فرض قابل تنظیم (۳۰٪)
- مدیریت کارکنان و درصد پیش‌فرض دستمزد
- ثبت مشتری و خودرو
- ثبت تعمیر و قطعات مصرفی با کاهش موجودی
- ثبت تسویه کامل یا پرداخت بخشی/صفر هنگام ثبت تعمیر و محاسبه خودکار بدهی مشتری
- ثبت دریافت‌های بعدی از مشتری برای تعمیر انتخاب‌شده و به‌روزرسانی مانده بدهی
- نمایش مبلغ پرداخت‌شده و بدهی باقی‌مانده در گزارش تعمیرات و گزارش هفتگی
- انتخاب قطعه از پنجره جداگانه همراه نمایش عکس؛ ثبت عکس برای هر قطعه
- تعیین درصد مستقل هر تعمیرکار؛ لازم نیست مجموع درصدها ۱۰۰٪ باشد و باقی دستمزد سهم تعمیرگاه است (مجموع بیشتر از ۱۰۰٪ مجاز نیست)
- ثبت مساعده، پرداخت، بدهکاری و بستانکاری کارکنان
- گزارش تعمیرات و مانده حساب ماهانه با قالب ماه `YYYY-MM`
- خروجی گزارش هشدار قطعات کم‌موجودی برای ارسال رسمی به صاحب‌کار
- خروجی گزارش هفتگی با انتخاب بازه تاریخ؛ شامل تعمیرها، قطعات مصرف‌شده، سهم اجرت تعمیرکاران و تراکنش‌های حساب کارکنان
- گزارش‌ها به شکل فایل HTML سازگار با Microsoft Word و با پسوند `.doc` ذخیره می‌شوند؛ در Word قابل باز کردن و ارسال هستند. گزارش ماهانه و هفتگی سهم صاحب‌کار و کارکنان را جداگانه نشان می‌دهند؛ مبنای سهم کارکنان فقط اجرت است و ارزش فروش قطعات کاملاً برای صاحب‌کار محسوب می‌شود

## محدودیت‌های فعلی
این نسخه اولیه است. چاپ صورتحساب، تقویم شمسی، ویرایش/لغو تعمیر، ویرایش/لغو تعمیر، گزارش سود دقیق و پشتیبان‌گیری خودکار هنوز پیاده‌سازی نشده‌اند. پرداخت مشتری در دیتابیس و فرم ثبت دریافت بعدی پشتیبانی می‌شود. قبل از استفاده عملی، حتماً تست و از فایل دیتابیس نسخه پشتیبان تهیه کنید.


## تغییر رمز ورود
پس از ورود به برنامه، در بخش «قطعات و انبار» روی دکمه «تغییر رمز ورود» بزنید. رمز فعلی را وارد کنید، رمز جدید را حداقل با ۴ کاراکتر تعیین و تکرار کنید. رمز به‌صورت هش‌شده در جدول AppSettings ذخیره می‌شود. رمز اولیه در اولین اجرای این قابلیت 1234 است؛ پس از تغییر رمز، رمز جدید برای ورود استفاده می‌شود.
